# 🐾 AdotePet

## Sistema de Gerenciamento de Adoção de Animais

Projeto desenvolvido para a disciplina de *Linguagem e Técnicas de Programação, do curso de **Análise e Desenvolvimento de Sistemas (ADS)*.

## 📌 Sobre o projeto

O AdotePet é um sistema desenvolvido em Linguagem C para auxiliar no gerenciamento da adoção de animais.

O sistema permitirá cadastrar animais disponíveis para adoção, consultar os animais cadastrados, cadastrar adotantes e registrar adoções.

## 💻 Funcionalidades previstas

- Cadastrar animais
- Listar animais disponíveis
- Buscar animais cadastrados
- Cadastrar adotantes
- Realizar adoções
- Consultar adoções realizadas
- Exibir estatísticas dos animais
